# 도쿄 건축 투어 (밐's Pick)

도쿄 건축물 38곳(10개 권역)을 걸어 다니며 보는 모바일 웹앱입니다.
안드로이드 크롬 기준으로 만들었고, 홈 화면에 앱처럼 추가해서 쓸 수 있습니다.

- 권역 탭 + 건축물 카드 (감상 포인트, 뷰포인트)
- **길찾기**: 버튼을 누르면 폰의 구글맵 앱이 열립니다 (내 위치 → 건축물, 도보 / 대중교통)
- 내 위치에서 **가까운 순** 정렬, 카드에 직선 거리 표시
- **방문 체크 · 즐겨찾기** (폰에 저장) + "즐겨찾기만" / "안 가본 곳만" 필터
- **전체 지도**: 38개 핀, 내 위치, 방문 여부 구분, 핀을 누르면 정보와 길찾기
- **스트리트뷰**: 가까운 거리 사진을 찾아 건물 쪽을 바라봄
- **오프라인**: 데이터가 끊겨도 목록과 체크 기록은 열림

## 처음 한 번만 하는 설정 (약 15분)

순서대로 하면 됩니다: **① 사이트 켜기 → ② 지도 키 만들기 → ③ 키 넣기 → ④ 폰 홈 화면에 추가**

### 1. 사이트 켜기 (GitHub Pages)

GitHub Pages는 이 저장소의 파일을 그대로 `https://` 주소로 보여주는 무료 기능입니다.
위치 기능과 오프라인 기능은 `https` 주소에서만 동작하는데, 이 저장소가 이미 GitHub에 있어서
새 계정이나 프로그램 설치 없이 클릭 몇 번이면 끝나는 가장 쉬운 방법입니다.

1. 이 저장소 페이지에서 위쪽 **Settings**(설정)를 누릅니다.
2. 왼쪽 메뉴에서 **Pages**를 누릅니다.
3. **Source**가 `Deploy from a branch`인지 확인합니다.
4. **Branch**에서 `main`을 고르고, 옆 칸은 `/ (root)` 그대로 두고 **Save**를 누릅니다.
5. 1~2분 뒤 같은 화면 위쪽에 주소가 나타납니다:
   **`https://mikmikmikmik77.github.io/tokyo-architecture-map/`**

이 주소가 앱 주소입니다. 이 단계만 해도 목록·길찾기·방문 체크는 바로 쓸 수 있습니다.
(지도와 스트리트뷰는 아래 키를 넣어야 열립니다.)

### 2. 구글 지도 키 만들기

> 예전 파일에 적혀 있던 키는 인터넷에 노출된 것으로 보고 **쓰지 않습니다.** 6번에서 삭제합니다.

1. <https://console.cloud.google.com/> 에 구글 계정으로 로그인합니다.
2. 위쪽 프로젝트 선택 칸 → **새 프로젝트** → 이름(예: `tokyo-arch`) → **만들기**.
3. **결제 계정 연결**: 구글 지도는 카드 등록이 필요합니다. 왼쪽 메뉴 **결제**에서 안내대로 등록합니다.
   - 구글 지도 플랫폼은 기능별로 매달 무료 사용량을 주고, 혼자 여행 중에 쓰는 정도는 보통 그 안에 들어옵니다.
     다만 무료 범위는 구글이 바꿀 수 있으니 [공식 가격표](https://mapsplatform.google.com/pricing/)에서 한 번 확인하세요.
   - 안심하려면 **결제 → 예산 및 알림**에서 예산을 1,000원쯤으로 만들어 알림을 받아 두세요.
4. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `Maps JavaScript API` 검색 → **사용**.
   (스트리트뷰도 이 API 안에 들어 있어서 다른 것은 켤 필요가 없습니다.)
5. **API 및 서비스 → 사용자 인증 정보 → + 사용자 인증 정보 만들기 → API 키**.
   만들어진 키(`AIza…`로 시작)를 복사해 두고, 그 키의 설정 화면에서 **제한 두 가지**를 겁니다.
   - **애플리케이션 제한사항** → `웹사이트` 선택 → **웹사이트 추가**에 아래 주소를 그대로 입력
     ```
     https://mikmikmikmik77.github.io/tokyo-architecture-map/*
     ```
   - **API 제한사항** → `키 제한` 선택 → 목록에서 **Maps JavaScript API** 하나만 체크
   - **저장**. (반영까지 최대 5분쯤 걸릴 수 있습니다.)
6. **예전 키 삭제**: 예전 파일을 만들 때 쓴 구글 프로젝트의 **사용자 인증 정보** 화면에서
   `AIzaSyBTeP…`로 시작하는 키를 찾아 **삭제**합니다.

이 키는 웹앱 특성상 누구나 볼 수 있는 파일에 들어갑니다. 그래서 위의 두 제한이 꼭 필요합니다.
제한을 걸면 다른 사람이 키를 복사해도 다른 사이트나 다른 API에서는 쓸 수 없습니다.

### 3. 키 넣기 — `config.js` 한 곳만

1. 이 저장소에서 **`config.js`** 파일을 누릅니다.
2. 오른쪽 위 **연필 모양**(Edit) 버튼을 누릅니다.
3. `"여기에_API_키_붙여넣기"` 에서 따옴표는 남기고 안쪽 글자만 복사한 키로 바꿉니다.
   ```js
   GOOGLE_MAPS_API_KEY: "AIza로_시작하는_내_키",
   ```
4. 오른쪽 위 **Commit changes…** → 다시 **Commit changes**.
5. 1~2분 뒤 앱 주소를 새로 열면 "전체 지도"가 나옵니다.

**지도 ID (선택):** `MAP_ID`는 `DEMO_MAP_ID`로 두어도 동작합니다. 이 값은 구글이 시험용으로 열어 둔 것이라,
오래 쓸 계획이면 콘솔의 **Google Maps Platform → 지도 관리 → 지도 ID 만들기**(유형: JavaScript)에서
내 지도 ID를 만들어 같은 파일에 넣는 것을 권합니다.

### 4. 폰 홈 화면에 앱처럼 추가

1. 안드로이드 **크롬**으로 앱 주소를 엽니다.
2. 오른쪽 위 **⋮** → **홈 화면에 추가** → **설치**.
3. 홈 화면의 "도쿄 건축" 아이콘으로 열면 주소창 없이 앱처럼 뜹니다.
4. **출발 전 와이파이에서 한 번 열어 두세요.** 그때 화면이 폰에 저장되어 오프라인에서도 열립니다.

## 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| 권역 바꾸기 | 위쪽 탭 |
| 길찾기 | 카드의 **도보** / **대중교통** → 구글맵 앱이 열림 |
| 가까운 곳부터 보기 | 아래 **가까운 순** (처음 한 번 위치 권한 "허용") |
| 다녀온 곳 표시 | 카드의 **방문 체크** |
| 필터 | 아래 **즐겨찾기만**, **안 가본 곳만** (둘 다 켜면 둘 다 만족하는 곳만) |
| 한눈에 보기 | 아래 **전체 지도** → 핀을 누르면 정보와 길찾기 |
| 돌아가기 | 폰의 뒤로 버튼 (지도·스트리트뷰가 한 단계씩 닫힘) |

지도 핀 색: 빨강 = 안 가본 곳, 회색 ✓ = 방문 완료, 노랑 ★ = 즐겨찾기, 파란 점 = 내 위치.

**알아둘 점**

- 방문 체크와 즐겨찾기는 **그 폰의 그 브라우저**에만 저장됩니다. 크롬의 "인터넷 사용 기록 삭제"에서
  사이트 데이터를 지우면 함께 지워지고, 시크릿 탭에서는 저장되지 않습니다.
- 카드의 거리는 **직선 거리**입니다. 실제 걷는 거리는 길찾기를 눌러 확인하세요.
- 구글 지도와 스트리트뷰는 인터넷이 있어야 합니다. 오프라인에서는 안내 문구가 나옵니다.
  지하나 데이터가 약한 곳에 대비하려면 구글맵 앱에서 도쿄 **오프라인 지도**를 미리 받아 두세요.
- 길찾기는 대부분 **건물 이름**으로 구글맵에 넘깁니다(정문 쪽으로 안내받기 위해서).
  엉뚱한 곳이 나오면 전체 지도에서 그 핀을 누르고 아래쪽 **"핀 좌표로 열기"** 를 쓰세요.

## 좌표 검증 결과 (2026-11-16)

예전 파일의 좌표는 AI가 써넣은 값이라, 38곳 전부를 공개 지리 데이터와 대조했습니다.
대조한 곳: **OpenStreetMap**(건물 윤곽 데이터), **위키백과·위키데이터**, **일본 국토지리원(GSI)**.
원자료는 `tools/coords_evidence.txt`, 채택한 좌표와 출처는 `places.js`에 있습니다.

| 구분 | 수 | 건물 |
|---|---|---|
| 서로 다른 출처 2곳 이상이 일치 | 30 | 아래에 없는 나머지 전부 |
| 출처 1곳(OpenStreetMap)만 확인 | 5 | 다이와 유비쿼터스 학술연구관, 아자부다이 힐즈(가든 플라자), 프라다 아오야마, 써니힐즈, 도큐 플라자 오모카도 |
| 출처 1곳뿐이고 정밀도 낮음 | 1 | 니콜라스 G. 하이에크 센터 (앱에 "핀 위치 대략" 표시) |
| **확인 못 함 — 기존 값 그대로** | **2** | **토즈 오모테산도, 더 주얼스 오브 아오야마** (앱에 "핀 위치 미확인" 표시) |

**기존 좌표가 100m 이상 어긋나 있던 곳 (고친 거리)**

다이와 유비쿼터스 학술연구관 375m · 아자부다이 힐즈 가든 플라자 347m · 써니힐즈 310m ·
국제어린이도서관 265m · 국립 요요기 경기장 253m · 스미다 호쿠사이 미술관 241m · 21_21 DESIGN SIGHT 235m ·
스파이럴 200m · 진구마에 공중화장실 200m · 힐사이드 테라스 163m · 니콜라스 G. 하이에크 센터 127m · 도쿄역 마루노우치 역사 102m

**알아둘 점**

- **확인 못 한 2곳**은 어느 출처에서도 좌표가 나오지 않았습니다. 추측으로 채우지 않고 기존 값을 그대로 두었으니
  핀 위치를 믿지 말고, 길찾기(건물 이름으로 구글맵 검색)를 쓰세요.
- **진구마에 공중화장실**: OpenStreetMap에 건축가가 "안도 타다오"로 기록된 진구도리 공원 화장실로 확정했습니다.
- **아자부다이 힐즈**: 가든 플라자 A~D 네 동 위치의 평균 지점입니다.
- **힐사이드 테라스**: A동 위치입니다. 뷰포인트로 적힌 C동만의 좌표는 찾지 못했습니다(같은 단지, 걸어서 1~2분 거리).
- **아사히 맥주 본사 & 슈퍼드라이 홀**: 황금 조형물이 있는 슈퍼드라이 홀 건물 위치입니다.
- **도큐 플라자 긴자**: 위키백과에 건물 이름이 "GinzaNovo"로 바뀌어 올라 있어, 길찾기를 이름이 아닌 좌표로 넘깁니다.
- 큰 건물은 좌표가 건물 **한가운데**라서 입구와는 수십 m 떨어질 수 있습니다.
- **길찾기 이름 검색은 구글맵에서 직접 시험하지 못했습니다.** 출발 전에 가고 싶은 건물의 길찾기를 한 번씩 눌러
  엉뚱한 곳이 나오지 않는지 확인하고, 이상하면 전체 지도 → 핀 → "핀 좌표로 열기"를 쓰세요.

## 건물 사진

카드마다 건물 외관 사진이 한 장씩 있습니다(38곳 중 36곳). 목적지에 도착했을 때 건물을 알아보는 용도입니다.

- 사진은 모두 **위키미디어 공용(Wikimedia Commons)** 의 자유 라이선스 사진(CC0, CC BY, CC BY-SA)이고,
  사진 아래에 저작자 · 라이선스 · 출처 링크를 표시합니다. 목록은 `photos.js`, `tools/photos_report.txt`에 있습니다.
- 사진은 앱과 함께 폰에 저장되어 오프라인에서도 보입니다.
- **사진이 없는 2곳**: 니콜라스 G. 하이에크 센터, 더 주얼스 오브 아오야마 (쓸 수 있는 외관 사진을 찾지 못함).
- 외관이 아닌 사진: 미야시타 파크는 옥상 공원, 다이칸야마 티사이트는 해 질 무렵 안뜰 모습입니다.
  아사쿠사 문화관광센터는 야경, 도큐 플라자 오모카도는 해 질 무렵 사진입니다.

## 파일 구성 (고칠 일이 생기면)

| 파일 | 내용 |
|---|---|
| `config.js` | **API 키, 지도 ID** — 직접 고치는 유일한 파일 |
| `data.js` | 권역과 건축물 문구 (원본 그대로) |
| `places.js` | 건축물 좌표와 좌표 출처, 길찾기용 이름 |
| `photos.js`, `photos/` | 건물 사진과 저작자·라이선스 정보 |
| `index.html`, `styles.css`, `app.js` | 화면과 동작 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 오프라인 저장, 홈 화면 아이콘 |
| `tools/` | 좌표 대조에 쓴 스크립트와 근거 자료 |
