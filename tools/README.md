# 좌표 근거 자료

`coords_evidence.txt` 는 2026-11-16에 공개 지리 데이터 API에 건물 이름으로 질의해 받은 좌표를
가공 없이 모은 것입니다. `places.js` 의 좌표는 이 자료에서 골랐습니다.

한 줄 형식: `건물ID|출처|검색어 또는 문서명|위도,경도|식별자|설명`

| 출처 기호 | 뜻 |
|---|---|
| `N` | OpenStreetMap (Nominatim 검색). 식별자 `w`=건물 윤곽, `r`=관계, `n`=점 |
| `O` | OpenStreetMap (Overpass 주변 검색) |
| `W` | 위키백과 문서의 좌표 |
| `D` | 위키데이터 항목의 좌표(P625) |
| `G` | 일본 국토지리원(GSI) 지명·주소 검색 |

`NONE` 은 결과 없음, `ERR` 는 서버의 요청 제한 등으로 조회 실패, `NOCOORD` 는 문서에 좌표 없음입니다.
지역이 전혀 다른 결과(예: GSI의 `東京都渋谷区東`, 오사카의 JP타워)는 동명이인 격이라 채택하지 않았습니다.
